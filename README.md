# Portal público do Bonfirely

Site oficial publicado pelo projeto `bonfirely` no Vercel. Ele oferece:

- download do instalador e da versão portátil servidos pelo Debian Bonfirely;
- descoberta automática da versão estável pelo manifesto público;
- estado de saúde do servidor por uma função Vercel sem credenciais;
- apresentação pública sem copiar código, marca ou assets de terceiros.

O Vercel não transporta mensagens, áudio, vídeo ou sinalização. Essas funções permanecem no servidor Bonfirely auto-hospedado.
