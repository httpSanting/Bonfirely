# Portal público do Bonfirely

Site oficial: [bonfirely.vercel.app](https://bonfirely.vercel.app).

O portal oferece o instalador Windows e o Android Alpha pelo GitHub, instruções de instalação e uma demonstração local da interface. A demonstração não envia mensagens nem inicia chamadas reais.

A consulta de disponibilidade usa uma função Vercel configurada para executar em São Paulo, resultados com horário de verificação e cache para reduzir consultas repetidas. A descoberta das versões Windows e Android é independente da disponibilidade do servidor de conversas; falhas nessa consulta preservam os links públicos já verificados.

Contas, conversas e mídias continuam no servidor Bonfirely. O portal e o GitHub distribuem os aplicativos; este repositório não contém o código privado do desktop ou as credenciais do servidor.

Windows e Android estão em Alpha. Baixe apenas os arquivos de uma publicação oficial e confira o manifesto de hashes da respectiva versão.
